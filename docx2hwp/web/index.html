    배운 규칙

      알아두면 좋아요

      • 파일은 서버로 올라가지 않습니다. 변환은 전부 이 브라우저 안에서 이뤄집니다.
      • 결과는 .hwpx입니다. 한글 2014 이상, 한글 뷰어, 한컴독스에서 열립니다. .hwp가 필요하면 한글에서 열어 다른 이름으로 저장하세요.
      • 수식은 그림이 아니라 편집 가능한 한글 수식입니다. 한글에서 두 번 누르면 수식 편집기가 열립니다.
      • 수식 교정 규칙은 이 브라우저에 저장됩니다. 다른 컴퓨터에서 쓰려면 내보내기로 저장해 두었다가 불러오기 하세요.
      • 처음 열 때 변환 엔진(약 10MB)을 내려받느라 몇 초 걸립니다. 그다음부터는 빠릅니다.
      본 제품은 한글과컴퓨터의 한글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다. GitHub
